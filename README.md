# Herald

> Distributed config propagation engine. Push typed config changes to thousands of running services in under 100ms — with consensus, vector clocks, quorum acks, and one-command rollback.

## Status: Under Construction

## Quickstart

```bash
docker compose up
herald cluster init --nodes 3 --quorum-size 2 --db postgres://localhost/herald
```
